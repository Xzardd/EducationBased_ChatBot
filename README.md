 QuickLearnerAI

QuickLearnerAI is an AI-powered personalized study assistant designed to break down complex topics into digestible, high-yield study guides. Built with Streamlit and powered by the Google Gemini API, it provides instant conceptual clarity, essential bullet points, practical examples, and self-test practice questions.

Features
- Instant Topic Breakdown: Enter any concept, subject, or technical query to get a targeted overview.
- Structured Learning Path: Generates core concepts, key takeaways, real-world examples, and self-assessment questions.
- Fast & Lightweight: Powered by Google's Gemini models and an intuitive Streamlit interface.

Tech Stack
- Frontend/App Framework: Streamlit
- LLM / API: Google Generative AI (Gemini API)
- Language: Python
- Environment Management: python-dotenv
